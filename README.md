# 🎵 Music Streaming App

A modern and responsive music streaming web application built with Next.js, TypeScript, and Tailwind CSS.

## 🚀 Features
- 🎧 Play and manage music tracks
- 📁 Create playlists
- ❤️ Like songs
- 🔍 Search functionality
- 👤 User authentication
- 📱 Responsive design (mobile + desktop)

## 🛠 Tech Stack
- Next.js
- TypeScript
- Tailwind CSS
- Node.js
- MongoDB (if used)
